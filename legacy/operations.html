APPLICATION CONFIGURATION

AI connection

Connect an OpenAI-compatible chat-completions API. The browser sends your key to this dashboard once; the key is encrypted before it is stored in PostgreSQL and is never returned to the browser.

Data access

Chat can read the factory, location, line, machine, metering, and dated work-plan tables in PostgreSQL, plus telemetry in ClickHouse. Queries have row and time limits. Actual production, shift attendance, tariffs, and verified anomalies are not connected yet.
